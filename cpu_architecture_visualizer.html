Hardware Orchestration

Linux Kernel -> Intel x86-64 Micro-architecture Mapping

01 / FORK (COW)

硬件检测 PTE 的 R/W 标志位。内核将其强制归零，导致 MMU 触发 #PF (缺页中断)。

CR3
--->
PTE [R/W = 0]
x--
RAM

02 / EXECVE (IRET)

内核复写内存栈。硬件执行 IRET / SYSRET 指令时，自动将栈上伪造的入口点装载入 RIP，实现对当前进程控制流的物理劫持。

Stack [RIP=0x400]
== IRET ==>
CPU.RIP

03 / SCHEDULE (CR3)

MOV CR3 汇编指令执行瞬间。虚拟地址空间全局替换，硬件 TLB (快表缓存) 同步被硬件逻辑强制清空作废。

MOV CR3, RAX
(Flush) -->
TLB

04 / SYSCALL (MSR)

用户态触发 SYSCALL。硬件直连 MSR_LSTAR 寄存器并覆盖 RIP，CPL 特权级在下一个时钟周期从 3 瞬间跃迁至 0。

MSR_LSTAR
==>
RIP
CPL: 3 -> 0
